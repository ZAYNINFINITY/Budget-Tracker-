Budget-Tracker- is a simple console-based C++ application that allows users to manage their incomes, expenses, and balance with persistent storage.

---

## Installing

**Compile the source code:**
```sh
g++ 33.cpp -o budget-tracker
```

**Run the application:**
```sh
./budget-tracker
```

---

## Usage

- Sign up or log in when prompted.
- Add income and expense transactions.
- View your current balance and transaction history.
- Data is saved locally in text files named after your username.
